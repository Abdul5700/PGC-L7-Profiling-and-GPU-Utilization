# Profiling and GPU Utilization Optimization

Comprehensive profiling of deep learning / matrix workloads using **PyTorch Profiler** and **CUDA Streams** on an **NVIDIA GeForce RTX 5060 Ti**. This project analyzes GPU idle gaps and achieves substantial speedups by eliminating pageable host-device copy bottlenecks and overlapping computation with data transfers using double buffering.

## 🔬 Theoretical Concepts

### 1. Pinned vs. Pageable Memory
* **Pageable Memory:** Default host memory allocated by the OS. The CUDA driver must first stage pageable buffers into an internal pinned buffer before triggering DMA, preventing asynchronous transfers.
* **Pinned Memory (Page-Locked):** Bound directly to physical RAM. The GPU DMA engine accesses it directly across PCIe via asynchronous DMA transfers (`non_blocking=True`).

### 2. Double Buffering & CUDA Streams
```
Stream 1 (copy_s):   [ H2D Batch 0 ] [ H2D Batch 1 ] [ H2D Batch 2 ] ...
                            |               |
                         copied[0]       copied[1]
                            v               v
Stream 2 (comp_s):           [ Kernels B0 ]  [ Kernels B1 ]  [ Kernels B2 ] ...
                                    |               |
                                 freed[0]        freed[1]
```
Two alternating device buffers (`buf[0]` and `buf[1]`) coordinated by CUDA events (`copied[k]` and `freed[k]`) prevent data hazards while completely hiding memory transfer latency behind kernel compute.

### 3. Roofline Model & Kernel Classification
$$\text{Arithmetic Intensity (AI)} = \frac{\text{FLOPs performed}}{\text{Bytes moved from GPU memory}}$$

* **GEMM (Matrix Multiply):** High arithmetic intensity ($\approx 249\text{ FLOP/byte}$), making it **compute-bound**.
* **Elementwise operations (ReLU, Mul, Add):** Low arithmetic intensity ($\approx 0.125\text{ FLOP/byte}$), making them **memory-bound**.
* **Reduction (Sum):** Low arithmetic intensity ($\approx 0.25\text{ FLOP/byte}$), making it **memory-bound**.


### Optimized Benchmark & Profiling
```bash
python gpu_workload.py --mode optimized --batches 20 --rows 4096 --cols 1024 --reps 1 --profile
```

### Analyze Profiler Traces
```bash
python analyze_trace.py trace_baseline.json trace_optimized.json
```
